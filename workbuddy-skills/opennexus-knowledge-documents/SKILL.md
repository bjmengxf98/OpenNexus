# OpenNexus 知识与文档

## 知识检索

1. 对制度、流程、历史口径和单位知识问题，先调用 `search_knowledge`。
2. 使用具体业务关键词检索；结果不足时改写查询词再次检索，而不是凭常识补造内部规定。
3. 回答中区分知识库原文事实、当前表格数据和模型建议。
4. 用户要求记住稳定偏好或工作背景时，确认后调用 `save_memory`；敏感信息、一次性内容和密钥不得保存。

## 起草内容

- WorkBuddy 当前模型负责理解检索结果和撰写正文，OpenNexus 不再调用聊天模型。
- 制度引用需注明材料标题或来源；无法确认条款时明确说“未检索到充分依据”。
- 会议纪要不得把讨论事项写成已决定事项；报告不得虚构数字。

## 生成正式文件

1. 与用户确认文种、标题、接收对象、署名、日期、版式和输出格式。
2. 当前模型先形成最终正文。
3. 调用 `generate_document` 进行确定性排版和文件生成。
4. 返回下载结果，并说明生成的是 Word、PDF 或其他格式。

## 业务数据引用

- 若文档需要实时任务、项目、人员或进展数据，先调用 `get_schema` 和 `list_records` 获取真实数据。
- 不使用旧对话中缓存的表结构或统计数字代替实时查询。
