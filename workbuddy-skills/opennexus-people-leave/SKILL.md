# OpenNexus 人员与休假

## 查询流程

1. 调用 `get_current_user`、`list_wps_files` 和 `get_schema` 获取当前用户、数据源和实时表结构。
2. 用 `list_records` 读取人员信息及休假登记；如姓名存储为 Link 字段，继续查询人员表获得真实姓名和部门。
3. 按当前本地日期判断：
   - 当前休假：开始日期不晚于今天，结束日期不早于今天。
   - 待休假：开始日期晚于今天。
   - 已结束：结束日期早于今天。
4. 不仅依赖文字状态字段；日期与状态冲突时指出数据异常。

## 登记休假

- 提取人员、休假类型、开始日期、结束日期和备注。
- 先查询人员记录 ID；Link 字段写真实记录 ID 数组。
- 计算天数时说明采用自然日还是工作日；规则不清楚时不要擅自计算。
- 使用 `create_records` 追加新记录，不复用历史空行；写入后回读验证。

## 工作衔接

- 用户要求分析休假影响时，再查询该人员未完成任务、近期截止事项和项目责任。
- 将“已分配任务”和“推测需要交接”分开表述。
- 只有用户明确要求时才通知本人或接手人，并使用正确消息渠道。

## 隐私

- 只返回完成请求所需的人员信息，不扩散联系方式、账号标识或无关请假原因。
