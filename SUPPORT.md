# Support / 使用支持

OpenNexus is a community open-source project maintained on a best-effort basis.

OpenNexus 是个人维护的社区开源项目，支持以维护者可用时间为限，不承诺响应时限或免费完成个性化部署。

## Public issues are suitable for / 适合公开提交

- Reproducible defects in the latest public version / 最新公开版本中可复现的缺陷
- Documentation corrections / 文档错误
- General feature proposals / 通用功能建议

## Public issues are not suitable for / 不适合公开提交

- Credentials, databases, logs containing personal data, or internal screenshots
- Production emergencies or guaranteed response-time requests
- Organization-specific data migration, custom business rules, or private deployment details
- 密钥、数据库、含个人信息的日志、内部业务截图、生产紧急故障和单位专属数据

Security vulnerabilities must follow [SECURITY.md](SECURITY.md) rather than a public issue.

安全漏洞请按照 [SECURITY.md](SECURITY.md) 私下报告，不要公开披露。
