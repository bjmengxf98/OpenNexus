共同基线之后的稳定版变化必须登记。若基线重新确定，必须新增记录说明，不能直接覆盖历史基线。

## 2. 状态定义

| 状态 | 含义 |
|---|---|
| `待提交` | 稳定版代码已修改，但尚无最终提交号 |
| `待评估` | 稳定版已提交，新项目尚未决定迁移方式 |
| `待迁移` | 已确认新版需要实现 |
| `迁移中` | 新项目已经开始处理 |
| `待验收` | 新版实现完成，尚未完成行为对照 |
| `已验收` | 新版通过契约测试和行为对照 |
| `不适用` | 有明确理由不进入新版，并已记录决定 |

稳定版维护对话只能创建记录、补充稳定版提交号和验证结果。只有新项目完成迁移验证后，才能将状态改为 `已验收`。

## 3. 迁移优先级

- `P0`：安全、数据损坏、权限、生产阻断修复；
- `P1`：数据库/API/配置变化、核心业务功能、外部集成协议；
- `P2`：普通功能、兼容性和重要界面行为；
- `P3`：不影响业务语义的体验改善。

## 6. 登记判断

以下情况必须登记：

- 新增、删除或改变用户可见功能；
- 修复会影响业务结果的缺陷；
- 修改工具参数、返回值、完成条件或重试逻辑；
- 修改 WPS、微信、OA、提醒、文档、表格或模型调用行为；
- 修改数据库表、字段、索引、迁移脚本或数据语义；
- 修改 API、Webhook、事件、环境变量、依赖或部署方式；
- 修改权限、确认、幂等、审计或错误降级策略；
- 改变 Token、上下文、工具选择和任务规划行为。

纯文字纠错或内部重命名只有在确认行为、接口、配置和数据都不变时才可不登记。

## 7. 已登记变更

### STABLE-20260828-01：任务真实写入门禁与微信桥接可选降级

- 日期：2026-08-28
- 稳定版分支：`codex/main-release-20260827`（已发布到 `main`）
- 稳定版提交：`60b8373`
- 优先级：P1
- 新版状态：待迁移
- 修改原因：模型曾在没有调用 `create_records` 时自行声称 WPS 返回 403；可选的个人微信桥接退出后又被固定每 30 秒重启，既缺少退出日志，又会无限产生进程和日志噪声。
- 用户可见行为：明确的“建立任务”请求只有在实际执行写入并回读确认后才会报告成功；真实工具错误会按工具回执说明，不再编造 403。微信桥接不可用时主系统继续工作，系统按指数退避尝试恢复，连续失败后暂停自动重启，并保留独立诊断日志。
- 涉及文件：`agent/assistant.py`、`app.py`、`core/wechat_supervisor.py`、`test_tool_planner.py`、`test_reminders.py`、`test_wechat_supervisor.py`、`CHANGELOG.md`
- 数据库变化：无
- API 或事件协议变化：无；沿用现有 WPS 工具和微信桥接接口。
- 配置、环境变量或依赖变化：无新增依赖；沿用 `WECHAT_SHOW_LOG`。默认将桥接子进程输出保存到 `logs/wechat-bridge-<account_id>.log`，达到约 2 MB 时保留一份轮转日志。
- 权限、副作用和兼容性：不改变原有任务字段、WPS 权限或微信启用方式；微信仍为可选能力。写入已成功但回读暂时失败时不会重复创建同一任务，而会如实提示“已写入、尚未完成回读确认”。
- 稳定版验证：覆盖主程序、智能体、提醒、工具治理、任务写入门禁和微信桥接的最终回归测试共 77 项通过；`app.py`、`agent/assistant.py`、`core/wechat_supervisor.py` 及相关测试均通过 `py_compile`。仓库原有联网调试脚本仍需外部凭证或不符合 pytest 收集约定，与本次修改无关。
- 建议迁移方式：按新版架构重新实现，不直接复制稳定版大型运行循环。
- 新版落点建议：将“写工具回执 + 回读验证 + 完成声明”实现为统一运行时完成策略；将微信等可选集成实现为带健康状态、退避和熔断的独立适配器。对应新版 Harness 原则 H06、H12、H15。
- 新版实现提交：待定
- 新版验收证据：待定
- 备注：迁移时应保留“任务完成以真实副作用为准”和“可选集成失败不影响核心服务”两项行为契约。

## 8. 最终审计

正式切换 OpenNexus Next 前，必须同时完成：

1. 比较共同基线至稳定版最终提交的全部 Git commit；
2. 比较受影响文件，而不是机械合并大型旧文件；
3. 核对数据库迁移、API、配置、环境变量和依赖；
4. 将本账本所有记录处理为 `已验收` 或有用户批准的 `不适用`；
5. 执行脱敏黄金任务和端到端回归；
6. 设定短暂稳定版功能冻结窗口，完成最后一次增量审计。
